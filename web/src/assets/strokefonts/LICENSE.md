# Single-line (stroke) fonts

These SVG fonts are single-stroke engraving fonts from the EMS collection by Evil Mad Scientist Laboratories,
converted by Windell H. Oskay and distributed in the `hersheytext` package (https://github.com/techninja/hersheytextjs).

| File | Font | Derived from |
|---|---|---|
| EMSAllure.svg | EMS Allure (script) | Allura by Rob Leuschke, TypeSETit |
| EMSReadability.svg | EMS Readability | — (Sheldon B. Michaels) |
| EMSFelix.svg | EMS Felix | — (Sheldon B. Michaels) |
| EMSTech.svg | EMS Tech | — (Sheldon B. Michaels) |

All four are licensed under the **SIL Open Font License 1.1** (https://scripts.sil.org/OFL) — see the
`<metadata>` block inside each file. They are bundled unmodified; AutoStudio uses them to animate "pen writing".
