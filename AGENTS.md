# AGENTS.md

## Design rules
- **Show, don't list:** anything with a *look* (styles, scene templates, layouts, animations, transitions, fonts, backgrounds, key-word styles, characters, widgets, export parts) is chosen from **thumbnails**, **animated** when it moves (play on hover / focus, cached still otherwise), and story structure is a **storyboard** of scene cards. Never a dropdown for these; dropdowns only for plain settings (numbers, formats, languages). Previews are drawn live by our own engine (`editor/pickers/LiveThumb.tsx`), never stored videos.
- **Every feature explains itself:** a ? help card (`src/help/topics.ts`: what / 3 steps / tips / problems / tour), helpful empty states with a do-it button, and a "Try with a sample" path where it makes sense.
- **AI hand-off is always the same numbered panel** (`editor/HandoffPanel.tsx`): ① Copy → ② Claude / ChatGPT / Gemini (first message new chat, next ones same chat) → ③ copy the answer → ④ paste here; plus "Do it for me" with the local assistant. No API keys.

## Layout
- `web/` Vite + React 19 + TS editor. Store: `src/store.ts` (zustand, undo/redo, multi-select, autosave to IndexedDB via `src/lib/db.ts`).
- Saved projects are migrated on load with `normalizeProject()` (`src/lib/project.ts`). Add defaults there whenever you add a `Project` field.
- Rendering is shared by preview and export: `src/render/renderer.ts` (`renderFrame`, `imagesNeededAt`, `clipSourceTime`), plus:
  - `motion.ts` (including the depth parallax camera)
  - `parallax.ts` (WebGL2)
  - `regions.ts` (animated details)
  - `captions.ts`
  - `typography.ts` (kinetic typography layouts; phrase picking lives in `src/lib/typography.ts`)
  - `effects.ts`
- Audio mix is shared by preview and export: `src/audio/mix.ts` (`buildMix`). SFX are synthesized in `src/audio/sfx.ts`; onset detection lives in `src/audio/beats.ts`.
- Export: `src/export/exporter.ts` (mediabunny CanvasSource + AudioBufferSource → MP4/WebM, plus WAV).
- In-browser AI: `src/ai/worker.ts` (transformers.js: Depth Anything V2 small and SlimSAM) behind `src/ai/vision.ts`. If WebGPU fails, the worker is restarted in WASM (CPU) mode, and inputs are downscaled to 1024 px.
- LLM client: `src/lib/llm.ts`, an OpenAI-compatible client with LM Studio / Ollama / Colab / custom presets. Gemma models get the system prompt folded into the first user message.
- Engine client: `src/lib/engine.ts`. API: `POST /jobs/{tool}` (multipart) → `GET /jobs/{id}` → `GET /files/{id}/{name}`. Tools: `tts`, `transcribe`, `imagegen`, `videogen`, `prompts`, `script`, `chat`, `upscale`, `video_upscale`.
  - `check()` detects the engine kind: our `/health`, or the TryAIToday notebook's `/api/health`.
  - `src/lib/tryai.ts` adapts `tts` / `transcribe` / `upscale` / `video_upscale` to their API: `/chatterbox|whisper|upscaler|vupscaler/start`, WebSocket `/ws/{id}`, `/file/{id}/{key}`. Their TTS is English-only and always needs a reference voice.
  - `videogen` = Wan 2.1 VACE 1.3B (`engine/server.py` `tool_videogen`). The UMT5 text encoder runs alone and is freed before the video model loads, so it fits a free T4. The UI is `editor/AiVideo.tsx`.
- Growth (`src/growth/*`, route `#growth/<tab>`):
  - `src/lib/youtube.ts`: Data API v3 with the user's key, Analytics v2 with an OAuth token. Includes the quota counter (resets at midnight Pacific), a localStorage cache, and pure scoring (`scoreKeyword`, `outlierScore`, `channelPulse`, `seoChecks`).
  - `src/lib/growth.ts`: niche RPM table, YPP targets, `readiness()`.
  - Desktop app: `electron/google.cjs` does loopback OAuth + PKCE with the user's own "Desktop app" client. Tokens are encrypted with `safeStorage`. Suggestions are proxied through the main process (browser version uses JSONP).
  - For tests, `localStorage.ytBase` points the client at `node scripts/fake-youtube.mjs`.
- Prompt Studio: templates and fill logic in `src/lib/prompts.ts`, page in `src/tools/PromptStudio.tsx`. Claude and ChatGPT take `?q=`; Gemini and Flow get the clipboard.
- Import review: `src/lib/timecode.ts` (`detectTime`) + `src/editor/review.ts` (bulk ops) + `ReviewTable.tsx`.
- Flow bridge: `src/tools/FlowBridge.tsx`. The prompt file is blank-line separated, the extension names downloads `NNN_vK`, and `project.flowScenes` maps sequence → time.
- `engine/server.py` + `engine/tts_worker.py` are the source of truth. `engine/AutoStudio_Engine.ipynb` is generated from them by `python engine/build_notebook.py`.
  - `--publish` also pushes the notebook to the public repo `SKILL3R01/autostudio-engine`. The app's "Open in Colab" button opens that repo.
  - The notebook is also bundled into the app (`EngineDialog.tsx`, `?raw` import) as a download fallback.
- Engine connection robustness:
  - Step 4 of the notebook waits for cloudflared's "Registered tunnel connection" and for the public `/health` to answer before printing READY. Asking a brand-new trycloudflare host too early can cache NXDOMAIN; `node scripts/tunnel-check.mjs [--gate]` reproduces this.
  - The app's `useEngine.check()` retries 5 times, calling `autostudio.flushDns()` (Electron `clearHostResolverCache`) between tries. The desktop app also enables secure DNS.
- Engine self-test: `GET /diagnostics` (server.py) checks the GPU, the Chatterbox venv, ctranslate2 CUDA, diffusers / WanVACEPipeline, ESRGAN weights, ffmpeg and disk, and returns the last jobs' errors. The notebook prints it on start; the app shows it under Connect engine → Check engine (Copy report).
- Engine auto-connect: the notebook prints two links.
  - `autostudio://engine?url=…`: the Electron protocol handler turns it into `#engine=`.
  - `http://localhost:5173/#engine=…`: for the browser version.
  - `App.tsx` handles `#engine=` in both cases.

  - `cdp-shot.mjs`: the browser picks its DevTools port (`--remote-debugging-port=0` → `<profile>/DevToolsActivePort`), the temporary profile is deleted at the end, `#demo` suites wait until the editor is really open after the first long wait, and `{ "waitFor": "js", "timeout": ms }` polls a condition instead of a fixed delay.
  - After adding a dependency, restart Vite with `--force` and warm it up first (otherwise a dep re-optimisation reloads pages).
- Typography studio v2.0 (`editor/TypoStudio.tsx`, at the top of the Typography panel):
  - The library is `lib/typostyles.ts`: `TYPO_DESIGNS` (21 built-ins), plus "My styles" in localStorage `typoDesigns`, applied with `applyDesign` / `designOf`.
  - `TypoBlock.style` (colours, per-role fonts, caps, glow) is merged by `palOf` / `pairOf` in `render/typography.ts`.
  - `TypoBlock.timing` is `word` / `lead` (−0.15 s) / `beat`. Beat snaps to `m.beats`, which `beatsFor` computes when a block uses it.
- Effects v1.13:
  - `render/shaderfx.ts`: a WebGL2 pass over the frame. Shader bodies define `vec4 effect(vec2 uv, vec4 frame)`, and `SHADER_HEADER` provides the uniforms plus `hash` / `noise` / `fbm` / `frameAt`.
  - Built-in shaders: fire, fog, godRays, filmBurn, glowPulse. Compile errors are re-numbered to the user's lines; broken shaders are skipped.
  - `render/particles.ts`: closed-form, deterministic particles (`ParticleSpec`, presets sparks / smoke / confetti / hearts / stars) plus `drawLightning`.
  - Custom effects live in `project.customEffects` and are applied by `EffectLayer.kind = 'custom'` + `customId`, with `params` → u_p1..u_p4.
  - UI is `editor/EffectsLab.tsx` (particle designer, code editor, AI writes the shader with one compile-repair round). `EFFECT_COST` labels heavy effects.
- Simple / Pro interface: `lib/uimode.ts` (`useUi`, localStorage `uiMode`, default Simple).
  - Simple mode groups the rail with `GROUPS` in `editor/Panels.tsx` and shows sub-tabs.
  - `Section` (`components/ui.tsx`) is foldable. `ADVANCED_SECTIONS` start folded in Simple mode; state is kept per title in `sec:*`.
  - The header hides the LLM / engine pills until they're configured. Settings → AI connections opens them via the `autostudio:open` event.
- Guided wizard: `editor/Wizard.tsx`, shown while `project.wizardStep` is set (Projects → New video (guided)).
  - It opens panels and dialogs through the `autostudio:tab` / `autostudio:dialog` window events.
  - Templates are in `lib/templates.ts` (`applyTemplate`: aspect, caption style, typography, colour look).
  - A project with no clips opens in the workspace (not the import screen) while the wizard is active.
- Version history: `lib/history.ts`. Snapshots of the project JSON are taken after autosave (≥ 2 min apart, last 30 kept) under `history:<id>`. Restore lives in `pages/HistoryDialog.tsx` (Projects → ⋯).
- Fast preview (`usePerf().fastPreview`): while playing, the preview runs at ×0.6 resolution and `RenderModel.draft` halves particle effects (`setEffectQuality`). Export never sets `draft`.
- Auto-edit: planning in `lib/autoedit.ts` (`planScenes`, `assignUnique`, `buildClips`, `applyAutoEdit`). The UI is `editor/AutoEditDialog.tsx`; it combines CLIP matches on your media, Colab imagegen and LLM queries.
- Media search: CLIP ViT-B/32 (8-bit, WASM) runs in `ai/worker.ts` (`clipImages` / `clipText`).
  - Vectors are base64 Float32 in `project.embeddings`, handled by `lib/mediasearch.ts` (`indexMedia`, `rank`). The UI is in `editor/MediaPanel.tsx`.
- Free-media search was removed in v3.0 (results did not match scripts). `lib/stocklinks.ts` keeps `keywordsFrom` and Pexels / Pixabay `siteLinks`; old `project.credits` are kept but unused.
- Colour grading: `render/grade.ts`.
  - `combineGrades` merges the project and clip grades. `needsGpu` decides between the WebGL2 pass (`gradeDrawable`, with a 3D LUT texture) and plain `ctx.filter`.
  - `parseCube` reads `.cube` files; LUTs are stored in `project.luts` as 8-bit RGB, base64.
  - The UI is `editor/GradeEditor.tsx`: looks, copy/paste via localStorage `gradeClipboard`, saved looks in `looks`.
- Hand-drawn text: `render/handdrawn.ts` (`drawOutlineWrite`, `drawPenWrite`).
  - Single-line fonts are parsed in `render/strokefont.ts` from the SVG fonts in `src/assets/strokefonts/` (EMS fonts, SIL OFL; see the LICENSE there).
  - Settings: `Overlay.write` / `penFont` / `writeTime`, and the typography enter animations `outline` / `pen`.
- Effects can be scoped (`EffectLayer.scope`: all / range / clips, plus fades); `effectAmount()` in `renderer.ts`.
- Per-clip motion overrides (`motionDepth`, `motionReverse`, `motionEasing`, `motionCustom` for the `custom` motion) go through `clipMotionXform()` in `render/motion.ts`.
- Performance profiles: `src/lib/perf.ts`.
  - `readHardware()` + `profileFor()` read hardware from the Electron preload (`electron/preload.cjs` → `window.autostudio.hardware()`) or browser APIs.
  - The profile tunes the preview size and the `mediaLimits` image cache.
  - `confirmHeavyAi()` warns before depth / SAM on Low.
- Layout: `editor/Splitter.tsx` (`usePanelSize`, persisted in localStorage). Settings → Reset fires the `layout-reset` event.
- `__APP_VERSION__` is injected from package.json by `vite.config.ts`.

## Desktop app
- Electron shell: `web/electron/main.cjs`. It serves `dist/` over the privileged `app://autostudio` scheme, so the app is a secure context and IndexedDB stays on one stable origin.
- `npm run app` runs the app locally. `npm run dist` builds the NSIS installer and the portable exe into `web/release/`.
- All runtime libraries sit in devDependencies on purpose: Vite bundles them, so electron-builder ships only `dist/` and `electron/`.
- In-app updates: `electron/updater.cjs`.
  - Reads `api.github.com/repos/SKILL3R01/AutoStudio/releases/latest`, downloads `AutoStudio-Setup-*.exe` from the release, and verifies it against the asset's GitHub `digest` (sha256).
  - Then runs it with `/S --updated --force-run` and quits.
  - The portable exe only gets a download link. Renderer state is in `src/lib/updates.ts`; the UI is in Settings → Updates, plus a header "Update" chip (daily background check).
  - Test with `AUTOSTUDIO_UPDATE_TEST_VERSION=1.0.0` to pretend to be old.
  - Releases must keep publishing the Setup exe (the workflow does) — the updater depends on it.
- Release workflow: `.github/workflows/release.yml`. A `v*` tag builds the exes and creates a GitHub Release.
- The app icon is generated by `python web/electron/make-icon.py`.
- To smoke-test the packaged exe, set `BROWSER=web/release/win-unpacked/AutoStudio.exe` and run `node scripts/cdp-shot.mjs "app://autostudio/index.html#demo" …`.
